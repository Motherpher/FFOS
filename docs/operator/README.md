## Reading policy

Operator documentation **interprets**, it does not establish architecture, deploy code, grant authority, or certify an agent. If the guide and a canonical source differ, record the conflict and follow the repository's governing source and decision process.

The GitHub Project is a planning projection; its status field is not a Director signature. Pius remains RESERVED/PENDING within the current FFOS technical baseline. Household Family is a merged implementation candidate, not a production-accepted agent. MESSI is a draft, not implemented.
