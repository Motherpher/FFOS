## How to use the directory

1. Choose the system; follow its **guide in the owning repo**.
2. Determine the guide's status and source revision before depending on a command.
3. To investigate active work, use its native Issues and the private Estate Portfolio where the Issue is represented.
4. If a guide disagrees with source, report the divergence with the file, Git SHA, observed behavior and owning decision; do not overwrite source law from this index.
5. Do not treat a Wiki feature flag as a published knowledge library or a Projects flag as an established board.

**No automatic Wiki/Project creation or external publishing has occurred in WP01.**
