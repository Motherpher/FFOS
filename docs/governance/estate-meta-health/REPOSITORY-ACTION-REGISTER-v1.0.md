## Triage conventions

- **GOV** constitutional/governed source; **APP** product/software; **DATA** analytics/data/spatial; **REF** public research/reference; **CLIENT** sensitive private/client/profile; **ARCH** historical archive; **CONCEPT** developmental concept/product.
- **WP** names denote *review/possible remediation relevance*, not an automatic requirement to edit that repo.
- **P0** safety/critical integrity; **P1** high-value coherence and practical usability; **P2** optional purposeful improvement; **P3** minimal/archival preservation.
- **EVIDENCE** short source observations from existing audits; **CHECK** means proposed verification rather than verified defect.
- For all repos **WP01 inventory** and **WP06 disposition** apply; table lists additionally targeted WP02–WP05.
- Specific owner is **unassigned until attested**, even if repo namespace is known.
