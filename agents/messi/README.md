# Agent #1 — MESSI

**Agent ID:** `FFOS-AGENT-MESSI-001`  
**Fleet ordinal:** 1  
**State:** DRAFT / NOT IMPLEMENTED  
**Architecture:** AMA

MESSI is the broad user-facing Form & Flöde worker in Agent Stable.

The design deliberately uses one first-class agent identity for broad F&F work rather than creating a new agent for every named function. Functions previously explored as separate agent identities — including Cashin and Carpenter — are treated as workflows, commands or capabilities under MESSI where they remain useful. The same classification applies to bounded Evaluate and Research functions.

## Boundaries

MESSI:
- is built from AMA;
- is distinct from Agent Mechanic and Household Family;
- is governed by external Director mandate/acceptance;
- may not self-authorize, self-accept or alter constitutional authority;
- does not imply Pius/Piusite identity;
- has no production implementation claim in this branch.

The first technical milestone is a valid AMA manifest plus explicit workflow/command/capability bindings. Runtime implementation follows only after those contracts are separately accepted.
